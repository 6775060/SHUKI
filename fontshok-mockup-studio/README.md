# FontShok Mockup Studio

אפליקציית Windows מקומית להפקת מוקאפים של אתרים לפרסום ממומן של פונטשוק.
Figma היא סביבת העיצוב, והאפליקציה היא מערכת השליטה.

```
URLs → סריקה (Playwright) → ממצאים + ראיות → אישור ידני → קבוצות של 4 אתרים × 4 פונטים
     → בנייה ב־Figma (שכפול תבנית, החלפת תמונות/טקסט/גרדיאנט) → בדיקות → אישור → ייצוא PNG
```

## מבנה

| תיקייה | תפקיד |
|---|---|
| `packages/shared` | טיפוסים, פרוטוקול אפליקציה↔פלאגין, בניית טקסט הכותרת והקרדיטים, צבעים |
| `packages/db` | SQLite (better-sqlite3), מיגרציות, ריפוזיטוריז, יומן פעולות, ג׳ובים להתאוששות |
| `packages/fonts` | נרמול שמות פונטים, התאמה דטרמיניסטית למאגר, ייבוא CSV |
| `packages/scanner` | צילום אתר ב־2x, זיהוי פונטים (`document.fonts` + computed style + קבצי פונט), חילוץ קרדיטים ושם פרויקט |
| `packages/imaging` | בחירת אזור החיתוך הטיפוגרפי, חיתוך לגודל המשבצת בתבנית, דגימת צבע מותג |
| `packages/grouping` | הרכבת קבוצות של 4 אתרים עם 4 משפחות פונט שונות |
| `packages/exporter` | שמות קבצים ותיקיות, FsGuard (כתיבה רק לתיקיות מורשות), כתיבה אטומית, בדיקות לפני אישור |
| `packages/figma-bridge` | שרת WebSocket מקומי (127.0.0.1 בלבד, קוד חיבור, origin של הפלאגין בלבד) |
| `apps/figma-plugin` | הפלאגין ל־Figma: שכפול תבנית, מילוי שדות `@…`, טביעת אצבע, ייצוא PNG |
| `apps/desktop` | Electron + React (עברית, RTL): אתרים, קבוצות ואישור, מאגר פונטים, היסטוריה, הגדרות |
| `test/fixtures` | אתרי בדיקה מקומיים ופלאגין מדומה שמדבר בפרוטוקול האמיתי |

## עקרונות שנאכפים בקוד

- **אין ייצוא בלי אישור.** אישור נשמר עם טביעת האצבע של הפריים. כל עריכה, בנייה מחדש או שינוי ב־Figma מבטלים אותו. לפני כתיבת קובץ כלשהו, כל ארבעת הפריימים נבדקים מחדש.
- **אין בדיית קרדיטים.** לכל ממצא יש ראיה (`evidence_json` חובה). קרדיטים אף פעם לא מאושרים אוטומטית. אם לא נמצא קרדיט, הוא לא מוצג, ושם הקובץ יקבל "ללא קרדיט".
- **תבנית המקור לא משתנה.** הפלאגין רק משכפל אותה, משווה טביעת אצבע לפני הבנייה ואחריה, ונוגע רק בשכבות ששמן מתחיל ב־`@`.
- **כתיבה לדיסק** מותרת רק בתיקיית הייצוא ובתיקיית הנתונים (כולל בדיקת symlinks). קובץ קיים לא נדרס.
- **אין כפילויות.** מפתח הכפילות הוא אתר + פונט + גרסת תבנית, ואתר שכבר יוצא לא מוצע שוב.
- **התאוששות.** ג׳וב שנקטע מסומן כנכשל בהפעלה הבאה. בחיבור לפלאגין, הפניות לפריימים שנמחקו מ־Figma מתנקות.
- **עובד בלי AI.** כל הזיהוי דטרמיניסטי.

## הרצה בפיתוח (Windows)

דרישות: Node.js 22 או 24 (גרסת LTS), Figma Desktop, והפונט `Sprinter_FS` מותקן במחשב.

```bash
npm install
npm run build
npm run dev
```
`npm run dev` מתקין קודם רכיב מוכן של `better-sqlite3` עבור Electron (`rebuild:electron`), ו־`npm test` מחזיר את הרכיב של Node. לא צריך Visual Studio, כי שום דבר לא מקומפל.

### טעינת הפלאגין ל־Figma (פעם אחת)
1. `npm run build:plugin`
2. ב־Figma Desktop: Plugins → Development → Import plugin from manifest… → `apps/figma-plugin/manifest.json`
3. פותחים את קובץ התבניות ומריצים את **FontShok Mockup Studio Bridge**.
4. מזינים את קוד החיבור שמוצג באפליקציה (מסך "הגדרות"). מהפעם השנייה החיבור אוטומטי.

### בניית קובץ התקנה
```bash
npm run dist:win
```
הפקודה יוצרת קובץ התקנה (NSIS) בתיקייה `apps/desktop/release`. הסריקה משתמשת ב־Microsoft Edge המותקן, כך שאין צורך להוריד דפדפן.

## תבניות ב־Figma

עמוד `Templates` מכיל פריימים בשם `tpl/<variant>/v<n>` (`single`, `split`, `split-thin`). השכבות:

| שכבה | תוכן |
|---|---|
| `@headline` | כותרת: שורה 1 Black, שורה 2 Regular, שורה 3 Bold. הסגנונות נדגמים מהתבנית |
| `@credits` | קרדיטים: תוויות Demi-bold, ערכים Regular |
| `@shot.main` / `@shot.secondary` | צילומים. התמונה מוכנה ב־2x ביחס המדויק של המשבצת |
| `@gradient.bottom` | רק צבע נקודת העצירה האטומה מוחלף |
| `#…` | שכבות קבועות, הפלאגין לא נוגע בהן |

תבנית חדשה מוסיפים כך: משכפלים פריים קיים לעמוד Templates, נותנים לשכבות את השמות שלמעלה, ולוחצים "סנכרון תבניות" באפליקציה.

## מאגר פונטים

**ייבוא מהאתר (מומלץ):** במסך "מאגר פונטים" לוחצים "ייבוא / עדכון מהאתר". האפליקציה קוראת את תפריט הפונטים ב־fontshok.co.il, ומכל עמוד פונט לוקחת את השם באנגלית ואת השמות הטכניים שבהם הפונט מוטמע (שמות `@font-face` ושמות קבצים, כמו `Discovery_Fs`, `SdHangar` או `KissofinFS`). מותר להריץ שוב בכל פעם שנוסף פונט לאתר, והכפתור לא מוחק דבר.
- שם טכני משויך לפונט רק אם הוא מכיל את שם הפונט, או אם הוא מופיע רק בעמוד של אותו פונט ואייתו כמעט זהה.
- שמות קודמים של פונטים מוגדרים ב־`FONTSHOK_FORMER_NAMES` (`packages/fonts/src/fontshokSite.ts`): פורטו (`PortoFs`, `SdPorto`) הוא דיסקברי. אתרים שהוטמע בהם פונט בשמו הישן מזוהים לפי השם החדש.
- שמות שלא שויכו בוודאות מוצגים לבדיקה ידנית.
- פונט שהוסר מהתפריט לא מבוטל אוטומטית, רק מדווח.
