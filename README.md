# שפע ובהירות

מערכת לשיפור ההתנהלות הפיננסית, הרגשית והרוחנית – לעוסק עצמאי ולמשק הבית.
המערכת רצה **על המחשב שלך בלבד**, ומושכת את התנועות מהבנקים ומכרטיסי האשראי בעצמה, כל בוקר.

- מסמך האיפיון המלא: [docs/SPEC.md](docs/SPEC.md)

## התקנה ב-Windows – הדרך הפשוטה

1. **ללחוץ פעמיים על `ShefaSetup.exe`.** אם מופיע "Windows הגן על המחשב שלך" – "מידע נוסף" ← "הפעל בכל זאת" (התוכנה לא חתומה דיגיטלית, וזה צפוי).
2. **"הבא" ← "התקנה" ← "סיום".** לא צריך Node.js, לא חלון שחור ולא הרשאות מנהל. אפשר לסמן "הפעלה אוטומטית עם Windows" כדי שהסנכרון היומי ירוץ.
3. המערכת נפתחת בחלון משלה. מעכשיו פותחים אותה מהסמל בשולחן העבודה או מתפריט התחל.
4. **לבחור סיסמת-על**, ואז **"חיבורים"** – כמו בשלבים 5–6 למטה. את הסיסמה עצמה אי אפשר לשחזר. אם שוכחים אותה, "שכחתי סיסמה" במסך הכניסה מאפס אותה: התנועות נשמרות, ורק את פרטי הכניסה לבנקים מזינים מחדש.

סגירת החלון לא עוצרת את המערכת – היא ממשיכה ברקע בשביל הסנכרון. לעצירה מלאה: תפריט התחל ← "עצירת שפע ובהירות". הסרה: הגדרות ← אפליקציות. הנתונים נשמרים ב-`%APPDATA%\ShefaUBehirut` ונשארים גם אחרי הסרה או עדכון; עדכון = פשוט להריץ ShefaSetup.exe חדש.

כניסה לבנקים נעשית דרך Chrome או Edge שכבר מותקנים במחשב.

### גישה מהטלפון

דרך [Tailscale](https://tailscale.com/download), רשת פרטית ומוצפנת בין המכשירים שלך:

1. להתקין את Tailscale במחשב ובטלפון ולהתחבר לשניהם עם אותו חשבון.
2. במערכת: "הגדרות" ← "גישה מהטלפון" ← "הפעלה". בפעם הראשונה Tailscale מבקש לאשר HTTPS – הקישור מופיע על המסך.
3. לפתוח בטלפון את הכתובת שמוצגת (`https://<שם-המחשב>.<…>.ts.net`), להזין את סיסמת-העל, ובתפריט של Chrome: "הוספה למסך הבית".

השרת עדיין מאזין רק למחשב עצמו; Tailscale Serve מעביר אליו רק בקשות מהמכשירים שלך. המחשב צריך להיות דלוק.

## התקנה ב-Windows – מהקוד (למי שמעדיף)

1. **להתקין Node.js** – גרסת LTS (22 ומעלה) מ-[nodejs.org](https://nodejs.org). ללחוץ "הבא" עד הסוף.
2. **להוריד את התיקייה** הזו למחשב (למשל ל-`C:\Shefa`).
3. **ללחוץ פעמיים על `install.bat`**. זה לוקח כמה דקות – הוא מתקין גם דפדפן פנימי שבעזרתו המערכת נכנסת לאתרי הבנקים.
4. **ללחוץ פעמיים על `start.bat`**. נפתח חלון שחור (להשאיר אותו פתוח) והדפדפן נפתח על המערכת.
5. **לבחור סיסמת-על.** אין לה שחזור – כדאי לרשום אותה במקום בטוח.
6. **מסך "חיבורים"** → לבחור את פאגי, להכניס את אותם פרטים שמכניסים באתר הבנק, "שמירה וסנכרון". אחר כך הפועלים, דיסקונט, מקס וישראכרט.

### הפעלה אוטומטית עם Windows
ללחוץ פעמיים על `autostart.bat`. מעכשיו המערכת עולה (ממוזערת) כשהמחשב נדלק.

**חשוב:** אחרי הפעלה מחדש של המחשב, הכספת נעולה. צריך לפתוח את `http://127.0.0.1:4870` ולהכניס את סיסמת-העל פעם אחת – ואז הסנכרון משלים לבד את מה שהוחמץ.

### הגדרות Windows מומלצות
- **שינה:** הגדרות → מערכת → צריכת חשמל → "מצב שינה": **אף פעם** (כשמחובר לחשמל).
- **הצפנת דיסק:** הגדרות → פרטיות ואבטחה → **הצפנת מכשיר / BitLocker** – להפעיל.

## אבטחה ופרטיות

- המערכת **קוראת בלבד**. אין לה שום יכולת להעביר כסף.
- הכול נשמר במחשב שלך, בתיקייה `%APPDATA%\ShefaUBehirut`. שום דבר לא נשלח לענן.
- השרת מאזין רק למחשב עצמו (`127.0.0.1`). הגישה מהטלפון עוברת דרך Tailscale Serve, שמעביר רק בקשות מהמכשירים שלך, וכל מכשיר צריך את סיסמת-העל.
- סיסמת-העל לא נשמרת בשום מקום. המפתח נמצא בזיכרון רק כשהמערכת פתוחה, ונמחק בלחיצה על "נעילה".
- **גיבוי והעברה למחשב אחר:** הגדרות ← "גיבוי והעברה למחשב אחר" ← "יצירת קובץ גיבוי". נוצר קובץ `.shefa` אחד, מוצפן בסיסמת-העל, שמכיל את כל הנתונים כולל החיבורים לבנקים. במחשב החדש: מתקינים, ובמסך הפתיחה בוחרים "שחזור מקובץ גיבוי" ומזינים את אותה סיסמת-על. שחזור על מחשב שכבר יש בו נתונים שומר קודם עותק של המצב הקודם בתיקיית הנתונים (`shefa-before-restore-….db`).

## למפתחים

```
server/   שרת Node.js + TypeScript (Express, SQLite המובנה ב-Node, israeli-bank-scrapers)
web/      ממשק React + Vite, מימין לשמאל
docs/     מסמך האיפיון
```

```bash
cd server && npm install && npm test      # 42 בדיקות
cd web && npm install && npm run build
cd server && npm start                     # http://127.0.0.1:4870
```

בניית תוכנת ההתקנה (צריך NSIS 3 ו-unzip; עובד גם על Linux):

```bash
node packaging/build-windows.mjs node-v22.x.y-win-x64.zip   # → packaging/out/ShefaSetup.exe
```

משתני סביבה: `SHEFA_WEB_DIST`, `SHEFA_DATA_DIR`, `SHEFA_PORT`, `SHEFA_SYNC_CRON` (ברירת מחדל `30 6 * * *`), `SHEFA_CHROME_PATH`, `SHEFA_SHOW_BROWSER`, `SHEFA_INITIAL_MONTHS` (ברירת מחדל 6).

`npm audit` מתריע על חבילות בשרשרת של puppeteer שמשמשות להורדת הדפדפן הפנימי בזמן ההתקנה (extract-zip, proxy-agent). הן לא מעבדות קלט חיצוני בזמן הריצה. התיקון תלוי בעדכון של `israeli-bank-scrapers`.
