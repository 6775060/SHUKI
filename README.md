# שפע ובהירות

מערכת לשיפור ההתנהלות הפיננסית, הרגשית והרוחנית – לעוסק עצמאי ולמשק הבית.
המערכת רצה **על המחשב שלך בלבד**, ומושכת את התנועות מהבנקים ומכרטיסי האשראי בעצמה, כל בוקר.

- מסמך האיפיון המלא: [docs/SPEC.md](docs/SPEC.md)

## מה עובד כבר עכשיו (שלב 0 – יסודות)

| יכולת | פירוט |
|---|---|
| **חיבור אוטומטי** | פאגי, הפועלים, דיסקונט, מקס, ישראכרט (ועוד בנקים וכרטיסים). סנכרון יומי ב-6:30 וגם בלחיצה |
| **כספת מוצפנת** | פרטי הכניסה לבנקים מוצפנים (AES-256-GCM) בסיסמת-על שרק אתה יודע |
| **סיווג אוטומטי** | מעל 200 כללים לעסקים ישראליים נפוצים, וכללים שלך שנלמדים מתיקונים |
| **עסקי / פרטי** | כל חשבון מקבל ברירת מחדל (פאגי = עסק), ואפשר להחליף בכל תנועה בלחיצה |
| **בלי ספירה כפולה** | חיוב הכרטיס החודשי בבנק, והעברה מהעסק הביתה, לא נספרים פעמיים |
| **תשלומים** | עסקאות בתשלומים מוצגות, כולל כמה כבר "תפוס" מהחודשים הבאים |
| **מסך בהירות** | נכנס, יצא, נשאר; עסקי מול פרטי; לאן הלך הכסף; יתרות |
| **ייבוא קובץ** | גיבוי כשאתר משתנה: Excel / CSV / קובץ xls שהבנק הוריד. בלי כפילויות |

## התקנה ב-Windows (פעם אחת)

1. **להתקין Node.js** – גרסת LTS (22 ומעלה) מ-[nodejs.org](https://nodejs.org). ללחוץ "הבא" עד הסוף.
2. **להוריד את התיקייה** הזו למחשב (למשל ל-`C:\Shefa`).
3. **ללחוץ פעמיים על `install.bat`**. זה לוקח כמה דקות – הוא מתקין גם דפדפן פנימי שבעזרתו המערכת נכנסת לאתרי הבנקים.
4. **ללחוץ פעמיים על `start.bat`**. נפתח חלון שחור (להשאיר אותו פתוח) והדפדפן נפתח על המערכת.
5. **לבחור סיסמת-על.** אין לה שחזור – כדאי לרשום אותה במקום בטוח.
6. **מסך "חיבורים"** → לבחור את פאגי, להכניס את אותם פרטים שמכניסים באתר הבנק, "שמירה וסנכרון". אחר כך הפועלים, דיסקונט, מקס וישראכרט.

### הפעלה אוטומטית עם Windows
ללחוץ פעמיים על `autostart.bat`. מעכשיו המערכת עולה (ממוזערת) כשהמחשב נדלק.

**חשוב:** אחרי הפעלה מחדש של המחשב, הכספת נעולה. צריך לפתוח את `http://127.0.0.1:4870` ולהכניס את סיסמת-העל פעם אחת – ואז הסנכרון משלים לבד את מה שהוחמץ.

### הגדרות Windows מומלצות
- **שינה:** הגדרות → מערכת → צריכת חשמל → "מצב שינה": **אף פעם** (כשמחובר לחשמל).
- **הצפנת דיסק:** הגדרות → פרטיות ואבטחה → **הצפנת מכשיר / BitLocker** – להפעיל.

## אבטחה ופרטיות

- המערכת **קוראת בלבד**. אין לה שום יכולת להעביר כסף.
- הכול נשמר במחשב שלך, בתיקייה `%APPDATA%\ShefaUBehirut`. שום דבר לא נשלח לענן.
- השרת מאזין רק למחשב עצמו (`127.0.0.1`). גישה מהטלפון תתווסף בשלב הבא, דרך רשת פרטית מוצפנת (Tailscale).
- סיסמת-העל לא נשמרת בשום מקום. המפתח נמצא בזיכרון רק כשהמערכת פתוחה, ונמחק בלחיצה על "נעילה".
- **גיבוי:** להעתיק את התיקייה `%APPDATA%\ShefaUBehirut` לכונן חיצוני (כשהמערכת סגורה). גיבוי אוטומטי מוצפן יתווסף בהמשך.

## כשמשהו לא עובד

| מה רואים | מה עושים |
|---|---|
| "פרטי הכניסה שגויים" | חיבורים → עריכה → לעדכן פרטי כניסה |
| "הבנק מבקש להחליף סיסמה" | להיכנס לאתר הבנק, להחליף, ולעדכן כאן |
| "שגיאה בחיבור לאתר" שחוזרת כמה ימים | כנראה הבנק שינה את האתר. בינתיים: להוריד Excel מהאתר ולהעלות ב"ייבוא קובץ". הספרייה מתעדכנת בדרך כלל תוך ימים, ואז מריצים שוב `install.bat` |
| רוצים לראות מה הדפדפן הפנימי עושה | להריץ: `set SHEFA_SHOW_BROWSER=1` ואז `start.bat` |
| צילומי מסך של כישלונות | נשמרים ב-`%APPDATA%\ShefaUBehirut\screenshots` |

## למפתחים

```
server/   שרת Node.js + TypeScript (Express, SQLite, israeli-bank-scrapers)
web/      ממשק React + Vite, מימין לשמאל
docs/     מסמך האיפיון
```

```bash
cd server && npm install && npm test      # 21 בדיקות
cd web && npm install && npm run build
cd server && npm start                     # http://127.0.0.1:4870
```

משתני סביבה: `SHEFA_DATA_DIR`, `SHEFA_PORT`, `SHEFA_SYNC_CRON` (ברירת מחדל `30 6 * * *`), `SHEFA_CHROME_PATH`, `SHEFA_SHOW_BROWSER`, `SHEFA_INITIAL_MONTHS` (ברירת מחדל 6).

`npm audit` מתריע על חבילות בשרשרת של puppeteer שמשמשות להורדת הדפדפן הפנימי בזמן ההתקנה (extract-zip, proxy-agent). הן לא מעבדות קלט חיצוני בזמן הריצה. התיקון תלוי בעדכון של `israeli-bank-scrapers`.
